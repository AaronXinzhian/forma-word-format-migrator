# Forma 赋式｜Windows 版使用说明

> 一份范本，万卷同式。

## 开始使用

1. 先把下载的 ZIP **完整解压**到一个普通文件夹，不要直接在压缩包里运行。
2. 双击 `FormaFushi.exe`（窗口内会显示“Forma 赋式”）。
3. 选择一份 Word 格式样板。程序会展示文档中实际使用的标题、正文、字符和表格格式，并把它保存到“我的格式库”。
4. 确认格式后选择要修改的 `.docx` 或 `.docm` 文件，指定保存位置，生成一个新文件。

程序自带文档处理环境，不要求安装 Python。Word 不是处理文件的必要条件，但建议用 Microsoft Word 打开结果并更新目录、域和交叉引用。

## 系统要求

- Windows 10 或 Windows 11，64 位 x64 系统。
- Windows 11 ARM64 可通过系统的 x64 兼容层运行本版本。
- 建议至少保留 500 MB 可用磁盘空间。

## 第一次启动

本版本暂未使用商业代码签名证书。Windows SmartScreen 可能显示“Windows 已保护你的电脑”，请先核对压缩包随附的 SHA-256；确认来源后可选择“更多信息”→“仍要运行”。

## 文档与格式库安全

- 程序始终另存新文件，不会覆盖格式源或目标原文件。
- 格式方案只保存样式、主题、字体映射、编号、页面设置和预览索引，不保存源文档正文、页眉页脚文字、批注、图片、宏或嵌入对象。
- 格式库默认保存在 `%LOCALAPPDATA%\FormaFushi\style-packs`。
- 删除格式方案时只会把对应 `.wfstyle` 文件移到 Windows 回收站。
- Mac 版创建的 `.wfstyle` 与 Windows 版兼容，可手工复制到上述目录使用。

## 应用格式时

会替换目标文档的样式系统、主题、字体表、标题编号和手工视觉格式；会保留文字、图片、表格结构、超链接、批注、脚注、页眉页脚和嵌入对象。

如果格式样板没有实际使用表格样式，程序会保留目标表格的外观和结构，只清除普通单元格段落里明确的“两字符首行缩进”。如果样板只有标题一至标题三，程序会延续其字体、字号、段落和编号逻辑补全标题四、标题五。勾选“所有标题向下调整一级”后，标题一会变成标题二，依次向下，标题九受 Word 上限保持不变。

## 常见问题

- 文件无法写入：先关闭 Word 中打开的目标或输出文件，再重试。
- 老式 `.doc`、加密或密码保护文件：请先在 Word 中转换或解锁。
- 字体预览不同：目标电脑没有安装样板使用的字体时，界面会使用替代字体显示；文档中的原字体名称仍会保留。
- 生成后分页有变化：字体环境和 Word 版本可能影响排版，建议最后快速检查分页、目录和编号。
